# TechNova Solutions - Sitio Web

## Descripción
Sitio web corporativo de TechNova Solutions, una empresa de tecnología e innovación, desarrollado como práctica colaborativa para la asignatura de Desarrollo Web Integral. El sitio incluye funcionalidades como autenticación de usuarios, consumo de APIs (clima simulado, usuarios simulados, soporte) y una interfaz moderna para promover los servicios tecnológicos de la empresa.

- HTML5
- CSS3

---

## APIs Consumidas
- Clima (simulado) - Para mostrar el clima de una ciudad ingresada por el usuario.
- Usuarios (simulados) - Para mostrar una lista de usuarios de prueba.
- Contacto/Soporte - Simulación de envío de formularios de contacto y soporte.
- Login - Simulación de autenticación de usuarios.
